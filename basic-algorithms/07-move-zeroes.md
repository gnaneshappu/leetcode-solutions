## Problem: Move Zeroes (Easy)

**Link:** https://leetcode.com/problems/move-zeroes/

### Approach

Move all non-zero elements to the beginning of the array while
preserving their relative order. After placing all non-zero
elements, fill the remaining positions with zeroes.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

The operation is performed in-place, so no additional array is
required.
